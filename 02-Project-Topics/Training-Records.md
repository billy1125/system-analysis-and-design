# 員工教育訓練紀錄系統

> **領域**：人力資源與工安｜**難度**：標準｜**這一題要想清楚的問題**：報名、簽到、完成是三件事，不能只用一個欄位表示
>
> 五題共通的名詞見本資料夾的[期末設計題目說明](README.md)〈五〉。

---

## 一、先看懂這件事在說什麼

### 1.1 一個你已經懂的類比

你在學校選課：先加選（報名），上課要點名（簽到），期末看成績決定過不過（完成）。

**這三件事不能用同一個欄位表示。** 加選了不代表有去上課，去上課不代表會通過，而只有通過的那一門才算學分。

**工廠的教育訓練就是這個結構**，只是「過不過」的判準是有沒有取得證明，而後果是能不能上機台操作。

### 1.2 現場實際長什麼樣

工廠的員工要受訓，理由有三種：

| 理由 | 例子 |
|---|---|
| 法規要求 | 堆高機操作、有機溶劑作業、急救人員、一般安全衛生教育訓練 |
| 客戶或認證要求 | ISO 內部稽核員、品質系統相關訓練 |
| 內部需要 | 新進人員訓練、新機台操作訓練、標準作業程序說明 |

第一類最要緊，因為它有法定時數與有效期限。**證照過期還在操作，被勞檢抓到是罰工廠，不是罰個人。**

一間中小型工廠的實際狀況大致是這樣：

| 面向 | 現況 |
|---|---|
| 誰在管 | 人資或管理部，通常一到兩個人兼著做 |
| 怎麼開課 | 排好日期發公告，各部門主管指派人員參加 |
| 怎麼簽到 | **一張紙本簽到表。** 上完課收回來，存進資料夾 |
| 怎麼統計 | 需要的時候把簽到表翻出來，打進 Excel |
| 怎麼知道誰該受訓 | 靠人資自己記，或稽核前一個月臨時清查 |

出問題通常是在稽核或勞檢的時候：

> 「請提供這三位堆高機操作人員的訓練證明，還有他們的證照有效期限。」
> 「……我找一下簽到表。」

### 1.3 名詞解釋

| 名詞 | 意思 |
|---|---|
| 課程 | 一門訓練的內容定義，例如「一般安全衛生教育訓練 6 小時」 |
| 梯次（開課場次） | 同一門課實際開設的一次，有日期、地點、講師與人數上限 |
| 報名 | 員工被指派或自行登記參加某一個梯次 |
| 簽到 | 上課當天實際到場的紀錄 |
| 完成（結訓） | 這位員工這門課算通過，通常要滿足出席時數，有些還要通過測驗 |
| 應受訓 | 依職務或法規，某位員工必須完成哪幾門課 |
| 有效期限 | 部分訓練有期限，過期要複訓 |
| 複訓（回訓） | 有效期限到了之後重新受訓 |
| 時數 | 法規常以時數為要求，例如「新僱勞工應接受 3 小時安全衛生教育訓練」 |

**「應受訓」與「已完成」是兩份不同的資料。** 前者來自職務與法規的規定，後者來自實際發生的紀錄。這套系統最主要的價值，就是把這兩份資料對起來，算出「誰還缺哪一門」。

## 二、為什麼需要一套系統

### 2.1 現在的做法有什麼問題

| 問題 | 具體情況 |
|---|---|
| 查不到個人的訓練履歷 | 要知道某人受過哪些訓，得翻遍所有梯次的簽到表 |
| 不知道誰還缺哪一門 | 「應該受訓的人」這份清單只存在人資的印象裡 |
| 期限沒有人追 | 證照到期前沒有提醒，通常是過期了才發現 |
| 簽到表會不見 | 紙本存放三年，中間搬過辦公室就找不到了 |
| 報名與實際到課對不上 | 報名 30 人來了 22 人，沒到的那 8 個沒有人追 |

### 2.2 系統要解決哪幾件事

1. 課程與梯次建檔，員工可以報名或被指派。
2. 上課當天能快速完成簽到。
3. 每位員工的訓練履歷隨時查得到。
4. 依職務算得出「應受訓但還沒完成」的清單。
5. 有效期限即將到期的名單能主動列出來。

## 三、誰會用這套系統

| 角色 | 現場的實際身分 | 在這套系統裡做什麼 | 多久用一次 | 最在意什麼 |
|---|---|---|---|---|
| 員工 | 全廠員工 | 看有哪些課可以報、報名、查自己的訓練紀錄 | 每季一兩次 | 介面要一看就懂，因為久久才用一次 |
| 人資（管理員） | 人資或管理部人員 | 建課程與梯次、管理報名、登記簽到與結訓、看缺訓清單 | 每週 | 簽到要快；缺訓與到期清單要準 |
| 主管 | 各部門主管 | 指派部屬受訓、看部門的完訓狀況 | 每月 | 我的人有沒有缺哪一門法定訓練 |

**「久久才用一次」是這一題的設計條件。** 員工一年只登入幾次，不可能記得操作方式，所以畫面要能在沒有教學的情況下用得起來。

## 四、要管哪些東西

以下用白話列出這套系統要記錄的資訊。**怎麼拆成資料表、每張表有哪些欄位，是你的工作，這裡不給。**

**關於每一門課**

- 課程名稱、內容說明
- 時數
- 屬於哪一類（法規、客戶要求、內部）
- 有沒有有效期限，多久

**關於每一個梯次**

- 是哪一門課
- 日期、時間、地點
- 講師
- 人數上限
- 目前開放報名還是已結束

**關於每一位員工在某個梯次的參與**

- 是誰、參加哪一個梯次
- 報名的時間、是自己報的還是被指派的
- 有沒有到（簽到）
- 實際出席時數
- 有沒有通過

**關於誰應該受訓**

- 哪一種職務應該完成哪幾門課

**注意這四組資訊的關係。** 課程與梯次是一對多，梯次與參與紀錄也是一對多；而「應受訓」那一組跟前面三組是分開的，它是規定不是紀錄。**四者怎麼關聯、各自有哪些欄位，你要自己決定。**

## 五、一次受訓的一生

```text
人資建立課程 → 開設梯次（狀態：開放報名）
  → 員工報名或被主管指派（狀態：已報名）
  → 上課當天簽到（狀態：已出席）
  → 未到（狀態：缺席）
  → 課後判定是否通過
       → 通過 → 完成（終點，並開始計算有效期限）
       → 未通過 → 需重上，回到「可報名下一梯次」
  → 梯次取消 → 所有報名紀錄一併作廢（終點）
  → 有效期限到期 → 這位員工這門課回到「應受訓」狀態
```

**例外會發生在這幾個地方，設計時都要有答案：**

| 環節 | 例外情況 | 你要決定什麼 |
|---|---|---|
| 報名 | 人數已滿還有人要報 | 候補？還是直接擋下？ |
| 報名 | 同一個人報了同一門課的兩個梯次 | 允許嗎？完成的算哪一次？ |
| 簽到 | 人到了但沒簽到 | 事後可以補登嗎？誰有權補？ |
| 出席 | 六小時的課只上了四小時 | 算完成嗎？時數不足要怎麼記？ |
| 完成 | 舊員工在系統上線之前就受過訓 | 這些歷史紀錄怎麼進來？ |
| 到期 | 證照到期了但人已經調到別的職務 | 他還算不算缺訓？ |

**「舊員工的歷史紀錄怎麼進來」這一條很多人會漏。** 系統上線那天，全廠每個人都是「零訓練紀錄」，缺訓清單會列出所有人——這件事要有處理方式，不能假裝不存在。

## 六、這一題要想清楚的地方

### 6.1 問題在哪

畫面上一定會有一欄「狀態」，用來表示某位員工在某門課的情況。

**直覺會想用一個欄位，值是「已報名／已完成／未完成」。但這樣會漏掉資訊。** 報名了沒去，跟根本沒報名，在管理上是兩件事；去了但時數不足，跟去了而且通過，也是兩件事。

### 6.2 一個欄位裝不下的東西

一次受訓其實有三個獨立的事實：

| 事實 | 什麼時候發生 | 誰產生 |
|---|---|---|
| 報名了 | 開課前 | 員工自己或主管指派 |
| 出席了 | 上課當天 | 簽到動作 |
| 通過了 | 課後 | 人資依時數與測驗判定 |

三者不是同一條線上的三個點——**它們可以有不同的組合**：報名了沒出席、出席了沒通過、甚至沒報名但當天臨時來上課。

用一個狀態欄位表示的話，「報名了沒出席」跟「出席了沒通過」會被迫共用同一個值，統計就分不出來了。

### 6.3 兩種做法，各自的代價

**做法 A：一個狀態欄位，用值來區分**

| | |
|---|---|
| 好處 | 資料表簡單，查詢直接 |
| 代價 | 狀態的值會越加越多（已報名、已簽到、缺席、時數不足、已完成、未通過……），而且**看不出時間順序** |
| 什麼時候會出問題 | 要回答「這一梯報名 30 人，實際來了幾人」時，得從狀態值反推 |

**做法 B：三個事實各自有欄位或紀錄**

| | |
|---|---|
| 好處 | 每一件事發生的時間與執行人都留得下來，統計想怎麼算都可以 |
| 代價 | 欄位變多，畫面要決定顯示哪一個，而且**「目前狀態」變成算出來的** |
| 額外問題 | 三個事實之間的合法組合要定義清楚，否則會出現「沒報名卻通過」的資料 |

### 6.4 這一題會逼你回答什麼

期末第 3 項要求你畫狀態機圖，第 4 項要求你交畫面欄位對照表。這一題的關鍵就在兩者的銜接：**畫面上那一欄「狀態」，在資料表裡對應的是一個欄位，還是三個欄位算出來的結果？**

能把這件事說清楚，代表你理解了「畫面上的一欄不等於資料表的一欄」。這是本題最主要的學習點，也是訪談一定會問的地方。

**要選 A 還是 B，你自己決定，理由要寫進第 8 項的設計決策紀錄。**

## 七、容易走偏的方向

| 走偏的做法 | 為什麼不對 |
|---|---|
| 把報名、簽到、完成擠成一個欄位 | 這就是第六節的核心問題。統計會做不出來 |
| 做成線上課程平台（放影片、線上測驗、發證書） | 那是另一個領域。本題只管「誰上了什麼課、通過沒有」 |
| 做成自動排課或人力調度最佳化 | 演算法會吃掉整份報告 |
| 忽略「應受訓」這一組資料 | 少了它，系統只是一本電子簽到簿，算不出誰缺訓 |
| 用人臉辨識或指紋簽到 | 要接硬體的一律界外。掃員工證或輸入工號就夠了 |
| 忽略有效期限與複訓 | 法定訓練最主要的管理價值就在期限 |

## 八、第一週建議做什麼

1. **去找一張真的簽到表與訓練紀錄卡。** Google「教育訓練簽到表 範本」「員工訓練紀錄卡」找得到大量實例。把每一個欄位抄下來，逐一問：這一欄是誰填的？填了給誰看？
2. **查一條真的法規要求。** 勞動部的「職業安全衛生教育訓練規則」規定了新僱勞工的時數與哪些作業需要證照。查一項出來，你就知道「有效期限」這個欄位為什麼存在。
3. **找一位打過工或實習過的同學問十分鐘**：報到的時候上了什麼課、有沒有簽到、有沒有拿到什麼證明。
4. **決定第六節那個取捨**（一個狀態欄位或三個事實），把理由寫成三句話。這三句話會直接進第 8 項的設計決策紀錄。

第 4 步最重要。**這個決定做完，這一題有一半就想通了。**
