# 量具校驗管理系統

> **領域**：品質管理｜**難度**：入門｜**這一題真正要想的問題**：「即將到期」與「逾期」不存在任何資料欄位，是算出來的
>
> 五題共通的名詞見本資料夾的[期末設計題目說明](README.md)〈五〉。

## 一、先看懂這件事在說什麼

### 1.1 一個你已經懂的類比

你家的體重計用了五年，站上去顯示 60 公斤。**但它真的準嗎？**

它可能已經偏了 2 公斤，而你完全不會發現——因為你沒有別的東西可以對照。要知道它準不準，得拿一個「已經確定重量」的東西去量，例如一袋確定是 10 公斤的米。量出來是 10 公斤，這台體重計就是準的；量出來 10.5 公斤，它就偏了。

**這個「拿已知標準去驗證量測工具準不準」的動作，就叫校驗。**

### 1.2 現場實際長什麼樣

工廠裡量東西的工具叫量具，常見的有游標卡尺（量長度與孔徑）、分厘卡（量更精細的厚度）、量表、扭力扳手（量螺絲鎖多緊）、溫度計、電子秤。

品管人員拿卡尺量產品尺寸，判定這批貨合格或不合格。**如果卡尺本身偏了 0.05 毫米，整批的判定就都不可信**——該退的收了，該收的退了。所以量具必須定期校驗。

一間中小型工廠的實際狀況大致是這樣：

| 面向 | 現況 |
|---|---|
| 數量 | 廠內有一兩百支到上千支量具，散在品管室、各條產線、工程部、實驗室 |
| 識別 | 每支貼一張標籤或雷雕一個編號，例如 `CAL-0138` |
| 週期 | 每支有自己的校驗週期，常見一年一次，精度要求高或使用頻繁的可能半年一次 |
| 怎麼校 | 送外部認證的校驗機構（會拿回一張校驗證書），或廠內自己校（用等級更高的標準件去比對） |
| 結果 | 合格（貼上新的合格標籤，寫下次校驗日）；不合格（調整後重新校，或直接報廢） |
| 現在怎麼管 | **一本 Excel。** 品保工程師每個月打開來，用眼睛看哪幾支快到期了，把那幾列標成紅色 |

出問題通常是在客戶或稽核員來的時候。他們會問：

> 「你這批產品的尺寸報告，是用哪一支卡尺量的？那支卡尺當時在校期內嗎？校驗證書給我看。」

這三個問題，Excel 翻不出來。

### 1.3 名詞解釋

| 名詞 | 意思 |
|---|---|
| 量具（計量器具） | 用來量測長度、重量、溫度、扭力等物理量的工具。卡尺、分厘卡、量表、扭力扳手、電子秤都是 |
| 校驗（Calibration，校正） | 拿已知準確度的標準去驗證量具準不準，並記錄偏差。**校驗本身不一定會修它**，只是量出它偏多少 |
| 調整 | 校驗發現偏差過大時，動手把量具調回準確範圍。調整後要重新校驗 |
| 校驗週期 | 兩次校驗之間的間隔，例如 12 個月。不同量具的週期可以不同 |
| 校期內 | 距離上次校驗還沒超過校驗週期，這支量具目前可以信任 |
| 逾期 | 已經超過應校驗的日期，還沒送校。**逾期的量具不得用於品質判定** |
| 標準件（標準器） | 精度比被校量具更高一級的參考物，例如塊規、標準砝碼。它自己也要定期送更高一級的機構校驗 |
| 追溯性 | 一支量具的準確度，能一層一層追到國家或國際標準。這是校驗制度存在的根本理由 |
| 外校 | 送到外部認證機構校驗，會取得一張校驗證書 |
| 內校 | 廠內自行校驗，用自己的標準件比對，紀錄留在廠內 |
| 合格標籤 | 校驗合格後貼在量具上的小標籤，通常寫校驗日、下次校驗日、執行人 |
| 報廢 | 量具損壞或調整後仍不合格，正式停用 |
| 品質管理系統稽核 | 客戶或認證機構來查工廠的品質制度是否有效運作。ISO 9001 與汽車業的 IATF 16949 都要求量具必須在校期內並可追溯 |

**「校驗」與「調整」是兩件事**，這一點很多人第一次接觸會混掉。校驗是「量出它偏多少」，調整是「把它調回來」。一支量具可以校驗合格而不需要調整，也可以調整之後還是不合格而必須報廢。你的資料設計要分得開這兩件事。

## 二、為什麼需要一套系統

### 2.1 現在的做法有什麼問題

| 問題 | 具體情況 |
|---|---|
| 到期完全靠人記得 | 品保工程師忘記開 Excel 的那個月，就沒有人知道有幾支已經逾期 |
| 沒有主動提醒 | Excel 不會告訴你「這支下週到期」，要有人主動去看 |
| 歷史紀錄查不出來 | 同一支量具的歷次校驗散在不同分頁，或者根本只留最後一次 |
| 逾期的量具照樣在用 | 系統上沒有任何機制擋住它，只能靠現場自己看標籤 |
| 保管責任不清 | 量具借給產線用，用完沒還回來，到期要送校時找不到人也找不到東西 |
| 稽核應對困難 | 客戶問「這批貨用哪支量具量的」，答不出來 |

### 2.2 系統要解決哪幾件事

1. 隨時看得出來哪些量具已逾期、哪些即將到期。
2. 每一支量具的歷次校驗紀錄都查得到，含執行人、結果與證書編號。
3. 逾期的量具在系統上被明確標示為不可使用。
4. 每支量具目前由誰保管、放在哪裡。
5. 稽核時能在一分鐘內調出任一支量具的完整校驗履歷。

## 三、誰會用這套系統

| 角色 | 現場的實際身分 | 在這套系統裡做什麼 | 多久用一次 | 最在意什麼 |
|---|---|---|---|---|
| 量具保管人 | 產線班長、品管人員、實驗室助理 | 查自己手上有哪幾支、什麼時候要送校；被通知時交出量具 | 每月一兩次 | 不要在生產最忙的時候被叫去交量具 |
| 校驗人員 | 品保部或計量室人員 | 執行內校或送外校、登錄結果、列印合格標籤 | 每週數次 | 登錄要快，一次可能要處理十幾支 |
| 品保主管 | 品保課長或經理 | 看逾期清單、核決報廢、應對稽核 | 每週一次，稽核期間每天 | 稽核時不要有任何一支逾期還在使用 |

**「多久用一次」這一欄會影響介面設計。** 校驗人員一週用好幾次、一次處理十幾支，他的畫面需要能快速連續登錄；量具保管人一個月才用一兩次，他的畫面要清楚易懂而不必求快。同一套系統對兩種使用頻率的人，設計取向不一樣。

## 四、要管哪些東西

以下用白話列出這套系統要記錄的資訊。**怎麼拆成資料表、每張表有哪些欄位，是你的工作，這裡不給。**

**關於每一支量具**

- 它是什麼（名稱、類型、規格、量測範圍、精度）
- 它的編號（廠內唯一）
- 廠牌型號、購入日期
- 校驗週期多久一次
- 用內校還是外校
- 目前放在哪、由誰保管
- 目前能不能用

**關於每一次校驗**

- 校驗的是哪一支量具
- 什麼時候校的
- 誰執行的（內校）或送到哪一家機構（外校）
- 是內校還是外校
- 結果：合格、調整後合格、不合格
- 量到的偏差值
- 證書編號（外校才有）
- 備註

**注意這兩組資訊的關係。** 一支量具會被校驗很多次，所以校驗紀錄不能塞進量具本身——那樣只留得下最後一次，追溯性就沒了。這是本題主檔與明細的分界，但**兩者各自該有哪些欄位、關聯怎麼建，你要自己決定**。

## 五、一支量具的一生

本題比較特別：其他四題的主角是「一張單子」，這一題的主角是**一支量具**。它的生命週期比單據長，可能十年，中間被校驗二十次。

```text
新購入
  → 建檔並執行首次校驗
  → 在校期內（可正常使用）
  → 接近到期（提醒保管人準備送校）
  → 送校中（這段時間量具不在現場）
  → 校驗合格 ─────────────→ 回到「在校期內」
  → 校驗不合格 → 調整 → 重新校驗 → 合格則回到「在校期內」
                              └→ 仍不合格 → 報廢（終點）
  → 逾期未送校（不得使用，但東西還在）
  → 損壞或遺失 → 報廢（終點）
```

**例外會發生在這幾個地方，設計時都要有答案：**

| 環節 | 例外情況 | 你要決定什麼 |
|---|---|---|
| 送校中 | 量具送出去了，現場要用怎麼辦 | 「送校中」要不要是一個明確的狀態？現場看到的是「不在」還是「送校中」？ |
| 到期 | 到期了，但那條產線正在趕貨不能停 | 系統要硬性擋下，還是允許主管例外放行並留下紀錄？ |
| 外校 | 送出去兩週了還沒回來，已經超過原本的到期日 | 這支算逾期嗎？它明明已經在處理中 |
| 報廢 | 報廢的量具，它過去量過的產品報告怎麼辦 | 歷史紀錄要不要保留？（提示：稽核會問） |
| 遺失 | 量具找不到了 | 這是報廢還是另一種狀態？ |

**「外校送出去還沒回來就到期了」這一條特別值得處理。** 它在現實中每個月都會發生，而且它會讓你的「逾期」定義變複雜——一支正在校驗途中的量具，算不算逾期？

## 六、這一題的設計難點

### 6.1 問題在哪

畫面上你一定會想顯示一欄「狀態」，內容是「在校期內」「即將到期」「逾期」。

**但資料庫裡沒有這一欄。** 這三個狀態是「上次校驗日 + 校驗週期」跟「今天」比較之後算出來的結果。

### 6.2 兩種做法，各自的代價

**做法 A：存成一個狀態欄位**

在量具資料上加一欄「狀態」，值是在校期內、即將到期或逾期。

| | |
|---|---|
| 好處 | 查詢與篩選最直接。要列出所有逾期的量具，一個條件就查得到 |
| 代價 | **這一欄必須有人或有程式每天更新。** 一支量具昨天是「即將到期」，今天可能變成「逾期」，但沒有任何人操作過它——資料不會自己變 |
| 沒更新會怎樣 | 那天畫面上顯示的狀態就是錯的。而且錯了沒人會發現，因為看起來很正常 |

**做法 B：不存，每次算出來**

資料只存「上次校驗日」與「校驗週期」，畫面上要顯示狀態時才計算。

| | |
|---|---|
| 好處 | **永遠正確。** 不需要任何人維護，也不會有「忘記更新」的狀況 |
| 代價 | 每次開清單都要對每一筆做計算。量具上千支時，「列出所有逾期的」這個查詢會比 A 慢 |
| 額外問題 | 「即將到期」的定義（提前幾天算即將）變成一條規則，而規則要放在哪裡是另一個決定 |

### 6.3 選了 B 之後還有一個問題

「提前幾天算即將到期」這個數字要放哪裡？

| 選項 | 好處 | 代價 |
|---|---|---|
| 寫死在程式裡 | 最簡單 | 要改天數就得改程式，而且沒有人知道它是幾天 |
| 存成一個系統設定值 | 可以改，改一次全廠生效 | 所有量具的提醒天數都一樣 |
| 每一支量具各自可設定 | 最靈活，重要量具可以提早提醒 | 每次建檔多一個欄位要填，而且多數人會留預設值 |

### 6.4 這一題會逼你回答什麼

期末第 4 項〈資料設計〉要求你交一張**畫面欄位對照表**，回答「這個畫面上的欄位最後存在哪裡」。

這一題的答案是：**「狀態」這一欄不存在任何地方。**

能把這句話寫進報告，並說明它是從哪兩個欄位算出來的、計算規則放在哪一層，代表你真的理解了畫面與資料的關係——那不是一對一的對應。這是本題最主要的學習點，也是訪談一定會問的地方。

**要選 A 還是 B，你自己決定，理由要寫進第 8 項的設計決策紀錄。** 兩個選擇都有人在真實系統裡用，各有適用情境。

## 七、容易走偏的方向

| 走偏的做法 | 為什麼不對 |
|---|---|
| 把「狀態」當成一個單純的資料欄位，不處理它怎麼更新 | 這就是第六節的核心問題。設了欄位卻沒說誰負責更新，等於設計沒有完成 |
| 把校驗紀錄併進量具主檔，只留最後一次 | 追溯性直接失效。稽核問「三年前這支的校驗結果」你答不出來。**這是本題最嚴重的錯誤** |
| 只做提醒，不做管制 | 提醒了但逾期的量具照樣能被登記使用，系統就只是一個會發通知的 Excel |
| 把「送外校」設計成要跟校驗機構系統連線 | 不必。外校的結果是人工登錄的，機構不會提供介接 |
| 做成自動排定送校批次的最佳化 | 演算法會吃掉整份報告，超出範圍。送校批次由品保人工決定 |
| 忽略「調整」這個動作，只有合格與不合格 | 現實中「調整後合格」是最常見的結果之一，漏掉它狀態機就不完整 |
| 把量具的保管人與借用紀錄做成完整的借還系統 | 範圍會爆掉。本題只需要記「現在由誰保管」，不必做借用單 |

## 九、第一週建議做什麼

1. **去找一張真的校驗標籤。** 系上實驗室的儀器、或 Google 圖片搜「校正標籤」。把上面每一個欄位抄下來，然後逐一問：這一欄是誰填的？填了給誰看？
2. **列出五種不同的量具，查它們的建議校驗週期。** 你會發現週期不一樣，這件事會直接影響你的資料設計。
3. **畫一張「一支量具的一生」草圖**，把第五節那張例外表裡你答不出來的問題圈出來。
4. **決定第六節那個取捨**（存狀態或算狀態），把理由寫成三句話。這三句話會直接進第 8 項的設計決策紀錄。

第 4 步最重要。**這個決定做完，這一題有一半就想通了。**
