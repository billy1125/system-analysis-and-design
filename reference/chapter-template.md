# 章節正文骨架範本

撰寫新章節時，複製本檔為專案根目錄下的 `0X-XXX.md`，刪除本說明區塊（含下方的第一條 `---` 分隔線），再從骨架開始填寫。骨架中以 `{}` 標示的都是占位符，完成後不應有任何 `{` 或 `}` 殘留，可用編輯器搜尋 `{` 做最後檢查。

骨架只規定形狀，不重述規則。撰寫時的完整規範見 `reference/chapter-writing-guide.md`，課程專屬的設定（標題副標、讀者程度、範例取材領域、固定引言、必讀標記的判準與權威章節清單放哪裡）見專案的 `CLAUDE.md`。章首必讀標記那則 blockquote 的措辭已寫進骨架，三種擇一貼上即可，不要自己重寫。以下四點最容易漏：

- `## 參考文獻` 必須是英文 APA 格式、依第一作者姓氏字母排序、各章約 20 筆以上。
- `## {中文數字}、學習重點總結` 固定是最後一個編號小節，位置緊接在 `## 參考文獻` 之前。
- 粗體 `**` 直接貼著中文字或英數字時，標記外側要補一個半形空白。
- 連結寫成 `[標題](檔名.md)`，連結文字用被連文件的大標題（`CLAUDE.md` 另有登記者從其登記）；**內文中的連結，標題前後加全形引號「」；表格與清單項目裡的連結不加引號**。
