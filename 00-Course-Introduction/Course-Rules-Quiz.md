# 課程規範理解測驗（自我檢核）

**系統分析與設計（IE226）115-1** ｜ 對應文件：[「SAD 課程介紹」](Course-Introduction.md)、[「報告規範」](Report-Rules.md)、[「成績計算規範」](Grading-Rules.md)、[「分組規範」](Group-Rules.md)、[「報告評量 Rubrics」](Rubrics.md)、[「報告內容」](Report-Contents.md)、[「額外投入加分」](Bonus-Rules.md)

> **這份測驗不計分、不用繳交，也不用給老師看。** 它的用途只有一個：讓你自己確認，那四份規範文件你是真的讀懂了，不是只有滑過去。

課程規範不會因為你沒讀而不適用。學期中真的出狀況時，老師是依文件處理，不是依你記得的版本——所以與其到時候才發現自己記錯，不如現在花十分鐘對一遍。

**怎麼做**：

1. 先把 `Course-Introduction.md`、`Report-Rules.md`、`Grading-Rules.md`、`Group-Rules.md`、`Rubrics.md` 與 `Report-Contents.md` 讀過一遍。
2. 全部 36 題都是是非題，對的寫 ○、錯的寫 ✕。**憑印象作答，先不要翻文件**，這樣才測得出你記得的版本對不對。第八區出自選讀的[「額外投入加分」](Bonus-Rules.md)，不打算多做的同學可以跳過那五題。
3. 全部答完再看文末的「解答與出處」。
4. 答錯的題目，回去把出處那一節重讀一次。錯在哪比錯幾題重要。

建議在 **第二週（9/16）上課前** 做完。有任何一題看完解答還是不懂，直接在課堂上問老師，或在 LINE 群組發問。
