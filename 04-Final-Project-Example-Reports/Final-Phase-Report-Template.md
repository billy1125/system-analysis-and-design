# 期末報告範本

> 這是期末書面報告的章節骨架，五題通用。每一節的引言說明這節要回答什麼，表格只給欄位與一列佔位，`{}` 裡的內容換成你們自己的。寫完把引言刪掉，轉成 PDF 繳交。
>
> 要交什麼以[報告內容](../00-Course-Introduction/Report-Contents.md)〈二〉為準，寫到多細看[期末範例報告](Final-Phase-Sample-Report.md)。範例處理了三項修改需求，所以每一節都分成 CR-01～CR-03；各組只有一項，不必分小節。
>
> 〈5.3〉的待決問題表，各題已經把題目列好，放在自己那一題修改需求提案書的〈五、你要交出什麼〉。
